Critical sequence

  • รวมหลักฐาน 3 ปี → Baseline → ตั้ง Target รายพื้นที่
  • ข้อตกลงชุมชน → Pilot แบบมีค่าตอบแทน → ประเมินผลสุทธิ → Scale
  • Dashboard / Claim Policy → Annual Report → Independent Review
  • Validated model → เชื่อมเข้ากับ ESG, HR, Procurement และ BD

Planning assumptions

แต่ละไตรมาสเป็นรอบ 3 เดือนนับจากวันที่ 28 สิงหาคมของทุกปี แถบลายหมายถึงงานประจำหรือเกิดซ้ำ สัญลักษณ์รูปเพชรคือรายงาน การประเมิน หรือ Decision Gate วันที่จริงควรปรับให้ตรงรอบงบประมาณ ฤดูกาล และช่วงน้ำขึ้น–ลงของแต่ละพื้นที่
