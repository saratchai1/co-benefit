Production upgrade

สิ่งที่ต้องเพิ่มเมื่อใช้งานจริงหลายคน

  1. Authentication: ระบุผู้บันทึกและสิทธิ์เผยแพร่
  2. Object storage: เก็บวิดีโอใน Cloudflare R2, S3 หรือ Vercel Blob
  3. Database: เก็บ Metadata กลาง เพื่อเปิดดูข้ามอุปกรณ์
  4. Consent & audit: ประวัติการแก้ไข สิทธิ์ใช้สื่อ และสถานะตรวจสอบ
